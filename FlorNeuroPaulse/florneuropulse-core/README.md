FlorNeuroPulse — Core Repository Layout
========================================
florneuropulse-core/
├── app/
│   ├── database/
│   │   └── schema.sql          # PostgreSQL DDL (users, baselines, sessions, telemetry, audit)
│   └── main.py                 # FastAPI + WebSocket /ws/stream + ONNX Runtime inference
├── scripts/
│   ├── train_and_export.py     # PyTorch CrossAttentionFusion + synthetic dataset + ONNX export
│   └── live_hud.py             # Multi-threaded OpenCV HUD (MediaPipe + Librosa + sounddevice)
├── models/
│   └── florneuropulse_core.onnx  # Exported ONNX model (generated by train_and_export.py)
└── README.md                   # This file

Privacy Architecture
--------------------
- Raw audio frames and video streams are processed transiently in-memory.
- Only scalar biomarker metrics (15D audio / 5D vision) and anomaly scores are persisted.
- PostgreSQL schema excludes binary media columns; audit log confirms raw_media_persisted=FALSE.
